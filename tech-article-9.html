Windows Server 2008的复活

时间：2023-06-03 20:40:00

分类：数码折腾 → 电脑折腾
标签：#操作系统 #老系统复活系列

Day1 安装系统

链接：https://www.123pan.com/s/6zDuVv-gaCHA.html
安装过程和2008 r2基本相同，不介绍了

Day2 驱动安装

还是看我2008 r2的那篇文章→https://blog.faryou.eu.org/tech-article-6.html

Day3 安装补丁

先装SP1和SP2。
链接：https://www.123pan.com/s/6zDuVv-9nCHA.html
再装上贴吧大佬星游12制作的Windows Vista补丁合集（因为Windows Server 2008和Windows Vista同为Windows NT 6.0内核，所以Windows Vista能用的补丁Windows Server 2008基本也能用），按照压缩包内的说明安装即可。注意分清楚32位和64位。
链接：https://www.123pan.com/s/6zDuVv-QnCHA.html
然后打开Windows Update，接收剩余更新即可。

Day4 安装软件

火狐浏览器

https://ftp.mozilla.org/pub/firefox/releases/
和2003一样，只能用52.9版本，H5视频补丁：https://www.123pan.com/s/6zDuVv-vcWHA.html

Office 2010

https://www.123pan.com/s/6zDuVv-TcWHA.html
也和2003一样，最高支持到2010版本

千千静听

https://www.123pan.com/s/6zDuVv-A8CHA.html
千千静听播放器，永恒的回忆

搜狗输入法

https://www.123pan.com/s/6zDuVv-3cWHA.html
老版本能用就行

微信

https://www.123pan.com/s/6zDuVv-hcWHA.html
3.2.1用起来比较稳定

QQ

https://www.123pan.com/s/6zDuVv-HcWHA.html
只能用国际版

某雷

https://www.123pan.com/s/6zDuVv-AcWHA.html
说实话，我是没办法才用它的，2008支持到极速版，比较流氓，所以我用老版本

WinRAR

http://www.winrar.com.cn/
WinRAR支持到最新版

PotPlayer

https://www.123pan.com/s/6zDuVv-QcWHA.html
PotPlayer还是很干净的，支持2008

Visual Studio 2010

https://www.123pan.com/s/6zDuVv-T8CHA.html
VS最高支持到2010

Hyper-V

开启方式和2008 R2一样，不介绍了

总结：Windows 2008的兼容性和2003差不多，而不是2008 R2，选择软件时注意兼容性
